# GPA Calculator

**Author:** Amro Al-Hamdan  
Java console program to calculate GPA, assign letter grades (A–E), and determine pass/fail. Supports **school** and **university** students.

---

## Key Features
- School & university student support  
- Semester & cumulative GPA calculation (university)  
- Detailed grade feedback  
- Highest & lowest marks displayed  
- Input validation for marks (0–100) and course hours (>0)  

---

## Usage
1. Compile & run `AverageCalculator_2_.java`  
2. Choose student type (1=School, 2=University)  
3. Enter marks and hours as prompted  
4. Program shows GPA, letter grade, and feedback  

---

## Grading
**School:** A:90–100, B:80–89, C:70–79, D:60–69, E:50–59  
**University:** A:≥84, B:≥76, C:≥68, D:≥60, E:≥50  
> Any course <50 → fail
