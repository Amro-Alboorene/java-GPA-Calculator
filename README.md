# GPA Calculator

**Author:** Amro Al-Hamdan  

A Java console-based application for calculating GPA for both school and university students.

---

📌 Features

- Supports both **school** and **university** students  
- Calculates **average / GPA** based on input  
- Handles **course hours (university students)**  
- Determines **pass/fail status**  
- Assigns **letter grades (A–E)**  
- Displays **highest and lowest marks**  
- Input validation for marks (0–100) and course hours (>0)  

---

## 🆕 Recent Improvements

- Refactored grading logic into a separate function  
- Reduced code duplication  
- Improved code structure and readability  

---

▶️ How to Run

1. Compile the file:
   ```
   javac AverageCalculator_2_.java
   ```
2. Run the program:
   ```
   java AverageCalculator_2_
   ```
3. Choose student type:
   - `1` → School student  
   - `2` → University student  
4. Enter marks and course hours as prompted  

---

🎓 Grading System

### School:
- A: 90–100  
- B: 80–89  
- C: 70–79  
- D: 60–69  
- E: 50–59  

### University (Zarqa University system):
- A: ≥84  
- B: ≥76  
- C: ≥68  
- D: ≥60  
- E: ≥50  

> Any course below 50 results in a fail.
